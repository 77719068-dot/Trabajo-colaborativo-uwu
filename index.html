Guía Rápida de Productos Notables

1. Cuadrado de un Binomio (Suma)
(a + b)² = a² + 2ab + b²

Ejemplo: (x + 3)² = x² + 2(x)(3) + 3² = x² + 6x + 9

2. Cuadrado de una Diferencia
(a - b)² = a² - 2ab + b²

Ejemplo: (x - 4)² = x² - 2(x)(4) + 4² = x² - 8x + 16

3. Suma por Diferencia (Diferencia de Cuadrados)
(a + b)(a - b) = a² - b²

Ejemplo: (x + 5)(x - 5) = x² - 5² = x² - 25

4. Cubo de un Binomio (Suma)
(a + b)³ = a³ + 3a²b + 3ab² + b³

Ejemplo: (x + 2)³ = x³ + 3(x²)(2) + 3(x)(4) + 8 = x³ + 6x² + 12x + 8

5. Cubo de una Diferencia
(a - b)³ = a³ - 3a²b + 3ab² - b³

Los signos se intercalan: (+, -, +, -).
